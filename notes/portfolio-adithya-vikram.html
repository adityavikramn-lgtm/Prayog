AI tools I used, and how

ToolWhat I use it for

Code that checks the mathsEvery number is calculated by code, never typed in by hand or taken from AI text. Each answer is checked a second, independent way (for example a simulation, or a different unit route). Right now 289 of 289 automatic checks pass.

My rule: AI for words, code for numbers

AI helps with
scripts, captions, simpler wording, Hinglish versions, hooks, new story settings for old questions
Code decides
every number, every graph, every frame of motion, and the second check of each answer

If an answer can't be checked, it is marked "needs teacher review" and never shown as final.

How one piece gets made

  1. Plan: pick the topic, the student level and one clear example.
  2. Write: draft the script with AI help, then rewrite it in plain, spoken language.
  3. Calculate: code works out every number and checks it a second way.
  4. Animate and render: video, Short, notes or worksheet, in English or Hinglish.
  5. Review: I watch or read everything before it goes out.
All questions, scripts, visuals and the mascot (Kan) are original. Thank you for reviewing my work. Adithya Vikram
